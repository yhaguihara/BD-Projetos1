# 🗄️ Projetos de Banco de Dados I — Scripts SQL

Repositório com scripts SQL de atividades de banco de dados, explorando exemplos de diferentes contextos, como automotiva, clínica, confeitaria e empresa.

## 📖 Sobre o projeto

O **BD-Projetos1** reúne scripts utilizados para praticar criação de estruturas, inserção e manipulação de dados e consultas SQL. Cada arquivo representa um cenário de exercício.

## ✨ Conteúdo

- 🚗 Banco de dados para cenário automotivo.
- 🏥 Exercícios relacionados a uma clínica.
- 🧁 Exercícios para uma confeitaria.
- 🏢 Exercícios de banco de dados para uma empresa.
- 🧱 Scripts SQL para praticar operações com tabelas e dados.

## 🛠️ Tecnologias utilizadas

- **SQL:** linguagem para definição e consulta de dados.
- **SGBD compatível:** utilize o sistema de banco de dados adotado nas aulas e confira eventuais diferenças de sintaxe.

## 📂 Estrutura do projeto

```text
BD-Projetos1/
├── Automotiva Novo.sql
├── Clinica.sql
├── Confeitaria.sql
├── Firma.sql
└── README.md
```

## 🚀 Como executar os scripts

1. Clone o repositório:
   ```bash
   git clone https://github.com/yhaguihara/BD-Projetos1.git
   ```
2. Entre na pasta:
   ```bash
   cd BD-Projetos1
   ```
3. Abra o arquivo `.sql` desejado em uma ferramenta de banco de dados e execute-o em um ambiente de teste.

**Atenção:** confira os comandos do script antes de executá-lo, pois alguns podem criar ou modificar bancos e tabelas.

## 🎯 Objetivo de aprendizagem

Praticar a criação e manipulação de bancos de dados relacionais, organizar scripts SQL e compreender como os dados são estruturados em diferentes cenários.
